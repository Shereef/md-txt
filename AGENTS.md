# AI Agent Rules

1. **Tech Stack**:
   - Node.js (>= 8)
   - TypeScript
   - Jest for testing
   - ESLint and Prettier for formatting and linting
2. **Commands**:
   - `npm run build`
   - `npm run test`
   - `npm run lint`
   - `npm run format`
3. **Guidelines**:
   - Keep changes scoped to the issue.
   - Maintain high test coverage.
   - Run `npm run commit-check` before concluding any code modifications.
